# brothers-online-work

## Install the website as an app

Open the HTTPS website in a supported browser and choose its **Install app** option. On iPhone or iPad, open the website in Safari, use **Share**, then choose **Add to Home Screen**. The app needs an internet connection to sign in, submit requests, and place orders.

## Production setup

See [OPERATIONS.md](OPERATIONS.md) for hosted database checks, PostgreSQL backups and restore steps, manual Render deployments, SMTP troubleshooting, and launch security tasks. Render auto-deploy is turned off in `render.yaml`.
